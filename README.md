One original pickup line, spoken by a vending machine to a passing human — ten years without a jam, until one passer-by makes the coil stick.

## The line

> Ten years, a thousand snacks, never jammed once — then you walked by, and now my coil's stuck on you.

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
